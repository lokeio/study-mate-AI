1.假设某计算机主存的读 / 写时间为 100ns，有一个指令和数据合一的 Cache，已知该 Cache 的读 / 写时间为 20ns，取指令的命中率为 98%，取数的命中率为 95%。在执行某类程序时，约有 1/5 指令需要存 / 取一个操作数。假设指令流水线在任何时刻都不阻塞，则设置 Cache 后，每条指令的平均访存时间约为（ ）。

A.26.4ns

B.32ns

C.14.7ns

D.18.6ns

答案：A

解析：取指令访问时间 20*98% + 100*2%，取数访问时间（20*95% + 100*5%）*1/5 ，二者相加为 26.4ns

单项选择题

2.某系统使用信号量实现进程互斥访问共享资源，信号量的初始值应设置为（ ）。

A.1

B.2

C.0

D. -1

答案：A

解析：信号量（Semaphore）是用于进程同步的机制，初始值的设置取决于具体场景：互斥访问：当信号量用于实现互斥（如临界区保护）时，初始值应为 1（即二元信号量）。进程进入临界区前执行 P 操作（信号量减 1），若初始值为 1，则减 1 后变为 0，表示资源被占用；进程离开临界区时执行 V 操作（信号量加 1），使信号量恢复为 1，允许其他进程进入。

4.RISC 指令系统的特点不包括（ ）。

A.寻址方式种类尽量减少，指令功能尽可能强

B.指令长度固定，指令种类少

C.增加寄存器的数目，以尽量减少访存次数

单项选择题

5.段页式存储管理中，地址映射表是（ ）。

A.每个进程一张页表，每个段一张段表

B.每个进程一张段表，每个段一张页表

C.每个进程一张段表，两张页表

D.每个进程的每个段一张段表，一张页表

答案：B

解析：在段页式存储管理中，为了实现从逻辑地址到物理地址的转换，采用两级映射。首先，每个进程都有一张段表，段表记录了进程中各个段的相关信息，包括段号、段长以及该段对应的页表起始地址等。然后，每个段对应一张页表，页表中记录了该段内各个页号与物理块号的映射关系。通过先查段表，再查对应段的页表，最终实现逻辑地址到物理地址的转换。

6.如果 I/O 设备与存储设备间的数据交换不经过 CPU 来完成，则这种数据交换方式是（ ）。

A.中断方式

B.DMA 方式

C.无条件存取方式

D.程序查询方式

答案：B

解析：直接内存访问（Direct Memory Access），通过 DMA 控制器（DMAC）实现 I/O 设备与内存的数据直接传输，全程无需 CPU 介入。CPU 仅在传输开始前配置 DMA 控制器，传输完成后处理中断，大幅提高效率。

A.顺序文件

B.有序文件

C.流式文件

答案：C

单项选择题

9.假设两个进程同时对A和B资源进行访问，进程1访问顺序A->B，进程2访问顺序B->A，则可能导致的问题是（ ）。

A.死锁

B.内存泄漏

C.优先级反转

D.竞态条件

答案：A

解析：死锁形成条件（本题均满足）：互斥条件：资源 A 和 B 同一时间只能被一个进程占用。请求与保持条件：进程 1 占用 A 后请求 B，进程 2 占用 B 后请求 A.不可剥夺条件：资源不能被强制抢占，只能由进程主动释放。循环等待条件：进程 1 等待进程 2 释放 B，进程 2 等待进程 1 释放 A，形成循环等待链。本题场景：若进程 1 先占用 A，进程 2 先占用 B，两者分别请求对方已占有的资源，会陷入互相等待，导致死锁。

10.（ ）是最适合使用SSD替代HDD的场景。

A.需要大量随机写入读取的时候

B.网络带宽不足的时候

C.存储冷数据的时候

D. 需要大量顺序写入读取的时候

答案：A

解析：SSD 在大量随机读写场景中凭借极低延迟和高 IOPS，远超 HDD 的性能表现，是替代 HDD 的最佳选择。D.需要大量顺序写入读取的时候：两者均可适用：顺序读写场景下，SSD 和 HDD 的差距不如随机读写明显（尤其对于高转速 HDD）。但 SSD 并非最优选择：若追求极致顺序速度，SSD 可能更优，但同等容量下成本更高；HDD 在顺序读写中仍能满足多数需求（如视频文件传输）。结论：非 “最适合” 场景。

A.FTP

B.Telnet

C.SNMP

D.SMTP

答案：C

解析：TCP（传输控制协议）是一种面向连接的、可靠的传输层协议，常用于需要高可靠性的数据传输场景。以下是对各选项的分析：A. FTP（文件传输协议）：基于 TCP 协议，使用 20（数据端口）和 21（控制端口）端口进行可靠的文件传输。B. Telnet（远程登录协议）：基于 TCP 协议，使用 23 端口，用于远程控制设备。C. SNMP（简单网络管理协议）：不属于 TCP 协议，而是基于UDP 协议（用户数据报协议），用于网络设备管理，注重传输效率而非可靠性。D. SMTP（简单邮件传输协议）：基于 TCP 协议，使用 25 端口，用于发送电子邮件。

18.增加服务器数量，是哪一种扩展？（ ）

A.水平扩展

B.垂直扩展

C.负载均衡

D.混合扩展

答案：A

解析：水平扩展（Scale Out）：通过增加服务器的数量，把负载（如用户请求、数据处理任务）分散到更多服务器上，以此提升系统整体处理能力。比如网站访问量增大，新增多台 Web 服务器组成集群共同提供服务 。对应题目：“增加服务器数量” 完全契合水平扩展的操作。垂直扩展（Scale Up）：不增加服务器数量，而是提升单台服务器的硬件性能，像升级 CPU、增加内存、扩大硬盘容量等，依靠增强单台服务器的能力来应对更高负载 。负载均衡（Load Balancing）：是一种技术手段或策略（并非扩展类型本身 ），作用是把网络请求、应用任务等合理分配到多个服务器（通常基于水平扩展后的服务器集群 ），让各服务器负载更均匀，目的是优化资源利用、提升系统稳定性和响应速度 。混合扩展：就是同时结合水平扩展和垂直扩展的方式，既增加服务器数量，也对部分服务器进行硬件升级。

21.数据库的脏读（Dirty Read）是指（ ）。

A.读取了未提交的数据

B.读取了其他事务插入的数据

C.读取了其他事务删除的数据

D.同一事务内多次读取结果不一致

22.数据库的 CAP 理论中，分布式系统无法同时满足（ ）。

A.一致性和分区容忍性

B.分区容忍性和一致性

C.一致性和可用性

D.可用性和分区容忍性

答案：C

解析：当网络分区发生时（必须满足分区容忍性），系统需要在一致性和可用性之间做出选择：牺牲可用性，保障一致性：如分布式数据库（如 ZooKeeper）在分区时停止服务，直到分区恢复，确保数据一致。牺牲一致性，保障可用性：如分布式缓存（如 Cassandra）在分区时允许返回旧数据，保证服务可用，但可能存在短暂数据不一致。一致性和可用性：在分区容忍性存在的前提下，二者无法同时满足，是 CAP 理论的核心矛盾。

23.数据库事务的“原子性”指的是（ ）。

A.数据满足完整性约束

B.并发事务互不干扰

C.事务要么全部执行，要么全部回滚

D.事务提交后结果永久保存

答案：C

解析：人机交互设计的用户体验五层模型从底层到顶层依次解决不同维度的问题，形成从抽象目标到具体实现的完整设计路径。以下是每层的核心设计目标及说明：1. 战略层：最底层，决定产品的 “根本性方向”。设计目标：明确用户需求和定义产品目标。2. 范围层：基于战略层，明确产品的 “具体功能边界”。设计目标：功能需求梳理和内容需求定义。3. 结构层：规划产品的 “逻辑架构”，解决 “如何组织功能与内容”。设计目标：交互逻辑设计和信息架构设计。4. 框架层：将逻辑架构转化为 “界面布局方案”，解决 “元素的空间排布”。设计目标：界面布局设计、导航设计、信息交互设计。5. 表现层：最顶层，关注产品的 “视觉呈现与感官体验”。设计目标：视觉设计、动效与反馈设计和感官体验优化。

51.软件开发中，实现代码重用的方式包括（ ）。

A.变量、常量、函数、模块、子程序

B.函数、对象、模块、类、算法

C.接口、函数、模块、文件、项目

D.属性、行为、对象、模块、构件

解析：代码重用指在软件开发中重复使用已有的代码逻辑，避免重复开发，提高效率和可维护性。实现代码重用的核心方式包括：函数 / 方法：将通用逻辑封装为函数（如计算折扣的calculateDiscount()），可在不同场景中调用。类与对象：通过面向对象编程（OOP），利用类的继承（如AdminUser继承BaseUser）、多态（同一接口不同实现）实现代码复用。模块 / 组件：将相关功能封装为独立模块（如 Python 的math模块、Java 的jar包），通过导入机制复用。算法与设计模式：通用算法（如排序、搜索）和设计模式（如工厂模式、单例模式）可抽象为可复用的代码模板。

C.商标权

D.商业秘密权

答案：A

59.某企业使用开源代码开发商业软件时，必须公开全部源代码的协议是（ ）。

A.GPL

B.MIT

C.BSD

D.Apache2.0

答案：A

解析：在开源协议里，GPL（GNU General Public License）有着 “传染性” 特点。要是企业使用了基于 GPL 协议的开源代码去开发商业软件，按照该协议要求，企业必须公开其衍生作品（也就是企业开发的商业软件）的全部源代码，并且新的作品也要采用 GPL 协议授权。而像 MIT、BSD 以及 Apache2.0 这些协议，它们则更为宽松。企业在使用遵循这些协议的开源代码时，是允许闭源的，只需保留原作者的版权声明就行，无需公开自身的源代码。
