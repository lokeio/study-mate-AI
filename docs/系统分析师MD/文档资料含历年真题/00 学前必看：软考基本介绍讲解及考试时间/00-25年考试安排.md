# 00-25年考试安排

2025上半年软考科目繁多，新手往往难以抉择。了解各科目内容，才能找到最适合自己的。

这里参考2024年软考考试安排，给大家详细介绍一下2025上半年开考科目考试内容及相应考试信息，希望对大家有帮助。

01 2025上半年开考科目

软考高级：信息系统项目管理师、系统分析师、系统架构设计师；

软考中级：软件设计师、网络工程师、软件评测师、电子商务设计师、嵌入式系统设计师、数据库系统工程师、信息系统管理工程师；

软考初级：程序员、信息处理技术员。

（以上内容仅供参考，以官方公告为准）

02 软考高级科目

信息系统项目管理师：

考试频次：一年考1次，一般在5月底

考核内容：信息化发展、信息技术发展、信息系统开发、信息系统管理、信息系统工程、项目管理概论、项目立项管理、项目整合管理、项目范围管理、项目进度管理、项目成本管理、项目质量管理、项目资源管理、项目沟通管理、项目风险管理、项目沟通管理、项目干系人管理、项目绩效域、配置与变更管理、高级科目管理、项目管理科学基础、组织通用治理、组织通用管理、法律法规与标准规范

岗位描述：从事信息系统项目管理的高级管理人员、高级项目经理等。

系统架构设计师：

考试频次：一年考2次，一般在5月底和11月初

考核内容：教程全书分上、下两篇，共计 20 章。上篇为综合知识，介绍了系统架构设计师应熟练掌握的基本知识，主要包括绪论、计算机系统、信息系统、信息安全技术、软件工程、数据库设计、系统架构设计、系统质量属性与架构评估、软件可靠性、软件架构的演化和维护、未来信息综合技术等诸多基本知识和方法。下篇为案例分析，分门别类地详细介绍了系统架构设计的相关理论、方法和案例分析，主要包括信息系统架构、层次式架构、云原生架构、面向服务架构、嵌入式系统架构、通信系统架构、安全架构和大数据架构等诸多设计理论和案例。

岗位描述：从事系统架构分析、设计与评估的高级技术人员

系统分析师：

考试频次：一年考2次，一般在5月底和11月初

考核内容：第二版教程分三篇内容，共计22 章。第一篇为基础知识，主要内容包括绪论、数学与工程基础、计算机系统、 计算机网络与分布式系统、数据库系统、企业信息化、软件工程、项目管理和信息安全等系统分析与 设计的基本知识。第二篇为关键技术，主要内容包括系统规划与分析、软件需求工程、软件架构设计、 系统设计、软件实现与测试、系统运行与维护等系统分析与设计技术。第三篇为案例实践，主要内容 包括 Web 应用系统、嵌入式系统、移动应用系统、大数据处理系统、微服务系统、信息物理系统等代 表性信息系统的分析与设计方法以及系统分析师论文写作要点。

岗位描述：在信息系统项目开发过程中负责制定信息系统需求规格说明书和项目开发计划、指导和协调信息系统开发与运行、编写系统分析设计文档、对开发过程进行质量控制与进度控制等的高级技术人员。

02 软考中级科目

软件设计师：

考试频次：一年考2次，一般在5月底和11月初

考核内容：计算机操作系统知识；数据结构；计算机网络概论；C程序设计语言，以及C++、JAVA中的一种程序设计语言；软件工程；结构化开发方法；面向对象技术；算法设计与分析；数据库技术基础；网络与信息安全；标准化和软件知识产权；软件系统分析与设计。

岗位描述：从事软件设计与开发工作的中级技术人员。

网络工程师：

考试频次：一年考2次，一般在5月底和11月初

考核内容：计算机网络概论、数据通信基础、局域网、无线通信网、 网络互连、网络安全、网络操作系统与应用服务器、组网技术、网络管理、网络规划和设计。

岗位描述：从事计算机网络系统的规划、设计，网络设备的软硬件安装调试，网络系统的运行、维护和管理的中级技术人员。

软件评测师：

考试频次：一年考1次，一般在5月底

考核内容：软件测试概述、软件测试基础、软件测评相关标准、软件测试过程和管理；基于规格说明的测试技术、基于结构的测试技术、自动化测试技术、基于经验的测试技术、基于质量特性的测试与评价；基于风险的测试、分层架构软件测试、事件驱动架构软件测试、微内核架构软件测试、分布式架构软件测试；新技术应用篇、移动应用软件测试、物联网软件系统测试、大数据系统测试、可信软件验证技术、人工智能时代下的软件测试技术发展

岗位描述：从事软件测试工作的中级技术人员。

电子商务设计师：

考试频次：一年考1次，一般在5月底

考核内容：电子商务概述、电子商务信息安全、电子支付技术与系统、电子商务物流与供应链管理、网络营销、电子商务法律规范与伦理道德、电子商务系统规划、电子商务系统程序设计、电子商务系统建设、电子商务系统的测试、电子商务系统的运维与评价、电子商务项目控制与优化、电子商务新技术与新应用、电子商务案例分析。

岗位描述：从事电子商务网站的建立、维护、管理和营销的中级技术人员。

嵌入式系统设计师：

考试频次：一年考1次，一般在5月底

考核内容：计算机系统基础知识，嵌入式系统硬件基础知识，嵌入式硬件设计，嵌入式系统软件基础知识，嵌入式系统设计与开发，嵌入式程序设计，嵌入式系统的项目开发与维护知识，嵌入式系统软件测试，嵌入式系统安全性基础知识，标准化、信息化与知识产权基础知识，嵌入式系统设计案例分析。

岗位描述：从事嵌入式系统的设计、开发和调试的中级技术人员。

数据库系统工程师：

考试频次：一年考1次，一般在5月底

考核内容：计算机系统知识、程序语言基础知识、数据结构与算法、操作系统基础、网络基础知识、数据库技术基础、关系数据库、SQL语言、关系型数据库NoSQL、系统开发和运行知识、数据库设计、事务管理、云计算与大数据处理、数据库主流应用技术、标准化和知识产权基础知识、数据库设计与案例分析

岗位描述：从事数据库系统设计、建立、运行、维护的中级技术人员。

信息系统管理工程师：

考试频次：一年考1次，一般在5月底

考核内容：信息化发展、信息技术发展、信息系统架构、信息系统治理、信息技术服务管 理、软件开发过程管理、系统集成实施管理、信息系统运维管理、云服务及其运营管理、项目管理、应用系统管理、网络系统管理、数据中心管理、桌面与外设管理、数据管理、信息安全管理、人员管理、知识管理、IT 管理标准化、职业素养与法律法规。

岗位描述：从事对信息系统的功能与性能、日常应用、相关资源、运营成本、安全等进行监控、管理、评估、提出系统改进建议的中级技术人员。

04 软考初级科目

程序员：

考试频次：一年考1次，一般在5月底

考核内容：

计算机系统基础知识、操作系统基础知识、程序设计语言基础知识、数据结构和算法、软件工程基础知识、数据库基础知识、网络与信息安全基础知识、标准化和知识产权基础知识、C程序设计、C++程序设计、Java程序设计。

岗位描述：从事软件开发和调试工作的初级技术人员。

信息处理技术员：

考试频次：一年考1次，一般在5月底

考核内容：信息处理技术基础知识、计算机系统基础知识、操作系统知识、文字处理、电子表格处理、演示文稿基础知识、数据库应用基础知识、计算机网络与互联网、信息安全与法律法规。

岗位描述：从事信息收集、存储、加工、分析、展示等工作，并对计算机办公系统进行日常维护的初级技术人员。

（以上内容仅供参考，以最新考纲为准）
